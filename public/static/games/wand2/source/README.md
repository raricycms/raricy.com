# Wand 2 精灵源图

这些源图由内置 image_gen 编辑原有的自制角色素材得到，完整提示词保存在 `prompts.json`。原角色参考图由用户提供。

- `attack-{down,left,right,up}.webp`：每张为 1024 × 1024 的透明 2 × 2 人物动作层，顺序为蓄力、挥击、跟随、收招。右手为空拳，剑和剑光在拼装时添加。
- `character-original.webp`：修鞋前的 1024 × 1024 角色表，作为局部修补的基准。
- `foot-{3,4}.webp`：向右行走和受击的鞋子修补源图；只采用配置中指定的脚部矩形，脸、头发、持剑手和其他帧均保留原像素。

在仓库根目录运行 `node scripts/prepare-wand2-sprites.mjs` 重建 `attack-body.webp`、`attack.webp` 和 `character.webp`。无需再次调用生成工具。

`../sprite-layout.json` 保存逐帧审核的右拳握点、剑角度和脚部修补范围。剑柄以握点为原点，人物拳头覆盖在柄上；剑尖、护手和柄共享同一轴线。左右朝向分别使用各自的右手，禁止用镜像改变朝向。背面朝向不显示胸前项链。

攻击表为 1536 × 1536，4 × 4 个 384 像素单元。每一行使用固定缩放比例，脚底基线为 354，所有像素与格线保留至少 8 像素透明边距。渲染为 144 像素方格，以补偿新增的透明留白，使人物在游戏中保持与行走表相近的大小。角色表仍为 1024 × 1024，256 像素单元。

`tests/unit/wand2-assets.test.ts` 检查实际输出的透明边距、尺寸、握点与局部修改范围；`wand2-render.test.ts` 检查游戏实际使用的切格与显示尺寸。更新源图或握点后，还需逐格检查手臂连接、鞋子朝向并慢放四方向动画，这些语义无法只靠像素测试判断。
