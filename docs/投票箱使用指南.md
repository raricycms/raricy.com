# 投票箱使用指南

投票箱是 Raricy.com 提供的投票工具：创建投票收集站友意见，也可以把投票作为互动小组件直接嵌入博客文章，让读者在文章里投票。

---

## 前置条件

使用投票箱需要已登录且通过邀请码认证（Core 用户及以上角色）。如果尚未认证，请先联系站长获取邀请码。

---

## 一、主页面

访问地址：`/vote`

主页面展示**全站所有投票**，每条显示标题、选项数与总票数（如"4 个选项 · 23 票"）、已锁定标记和 9 位投票 ID，点击可进入详情页。

顶部提供三项操作：

- **搜索跳转**：输入投票 ID，点击"前往"即可直接打开对应投票详情页。
- **使用指南**：打开你现在看到的这篇指南。
- **创建投票**：进入新建投票页面。

---

## 二、创建投票

点击"创建投票"按钮进入 `/vote/create`：

| 字段   | 要求                  | 说明              |
| ---- | ------------------- | --------------- |
| 投票标题 | 1–200 字，必填           |                 |
| 选项   | **2–10 个**，每个 1–200 字 | 默认两行，可"＋添加选项"或删除 |

填写完成后点击"创建投票"按钮，创建成功会自动跳转到该投票的详情页。

> - 每人最多创建 **100 个**投票（软删除的投票不占名额）。
> - 创建频率限制为每小时 10 次。

---

## 三、投票详情与参与

详情页顶部显示发起者、创建日期；已锁定或你已投过票时，还会出现对应徽章。

### 未投票时

列出所有选项，点击选中一个选项（高亮），再点"投票"按钮提交。投票成功后立即切换为结果视图。

### 已投票 / 已锁定

显示结果视图：顶部"共 X 票"，每个选项带**票数、百分比与进度条**，自己投过的选项会高亮标记。

规则：

- **每个账号每个投票只能投一次**，投过之后再点会提示"您已经投过票了"。
- 投票被**锁定**后任何人都不能再投，但可以查看结果。
- 每人每小时最多投票 **30 次**。

---

## 四、发起者管理

作为投票发起者，详情页底部会多出管理区域：

- **查看详细投票情况**：折叠面板按选项列出投票人用户名（未投的选项显示"暂无投票"）。仅发起者可见。
- **锁定投票**：确认后所有人不能再投票，结果保留可见。
- **解锁投票**：解除锁定，恢复投票。
- **删除投票**：删除后投票从列表消失、链接变为 404，**不可恢复**。

> 发起者之外的普通用户看不到上述管理按钮；站长可查看任何投票，但不能代删（删除入口仅发起者有）。

---

## 五、嵌入博客

这是投票箱与博客联动的方式：在博客正文写入 `[@投票ID]`，发布后该位置会渲染为投票的**只读结果视图**：

```markdown
大家觉得哪个方案好？

[@vOtE12345]
```

渲染效果：

- 每个选项的票数、百分比与进度条，顶部显示"共 X 票"。
- 如果你已投过票，自己投的选项会带 ✓ 高亮。

注意：

- 博客中的嵌入是**只读**的，参与投票请访问对应投票详情页 `/vote/<投票ID>`。
- 嵌入与剪贴板引用、图床图片共用每篇博客 **50 处**内容引用额度。
- 未登录或未认证的访客无法加载，该位置会显示可点击的 `[查看投票]` 链接。
- 投票 ID 为 9 位，与 8 位剪贴板、10 位图片不同；长度不符的 `[@...]` 不会被处理。

## 六、限制一览

| 限制项      | 数值            |
| -------- | ------------- |
| 每人最多创建   | 100 个投票       |
| 标题长度     | 1–200 字符      |
| 选项数量     | 2–10 个         |
| 选项长度     | 每个 1–200 字符   |
| 每人每投票    | 仅 1 票         |
| 创建频率     | 每小时 10 次      |
| 投票频率     | 每小时 30 次      |
| 投票 ID    | 9 位（区分大小写）   |
| 每篇博客最多嵌入 | 50 处引用（三种类型合计） |

## 七、常见问题

### Q: 投错了能改票吗？

不能。每个账号每个投票只能投一次，投票前请确认选项。

### Q: 为什么点投票提示失败？

常见原因：

1. 你已投过票（每人一票）
2. 投票已被发起者锁定
3. 每分钟/每小时的投票频率超限
4. 投票已被删除（页面直接 404）

### Q: 锁定投票和已投过票有什么区别？

锁定后**所有人**都不能再投（结果可见）；已投票只影响你个人（显示结果视图）。

### Q: 删除投票能恢复吗？

不能。删除后投票立即从列表消失、链接失效，此操作不可恢复。

### Q: 为什么我在博客里嵌入的投票没有显示？

加载失败时该位置会显示可点击的"加载失败"提示，可能原因：未登录或未认证、投票已删除、博客的 `[@id]` 引用超过 50 处。
