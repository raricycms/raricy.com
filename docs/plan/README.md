## 3. 更新约定

- 写明校对日期，区分未实施、部分完成、待验证、待决策与可选候选；索引整理不冒充重新校对。
- 完成一项后补实现 / 提交 / 验收依据；没有设备或性能证据的项目继续标待验证。
- 混合方案明确列出剩余范围；整份计划完成后，保留实施记录并更新本索引。
- 当前行为与约束以架构、规范、指南和代码为准；计划中的目标不提前写成已支持能力。
- 新增、移动或改名时同步 `docs/README.md`、`src/lib/docs-catalog.ts` 及全仓引用，
  按文档互指规则运行登记、引用与渲染守卫。
