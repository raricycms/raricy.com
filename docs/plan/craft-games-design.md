# 手工间小游戏设计

状态：三款游戏已按「连贯沉浸」重做（2026-10-26）。

## 1. 整体定位

在「玩具」区增加「手工间」合集，首批包含织布机、剪纸、水面印花。
面向想随手创作、放松几分钟的玩家，每次体验以做出一件可以保存的小作品为目标。

三款游戏分别突出制作的节奏、展开成品的惊喜、颜色变化的自由探索。
以自由创作为主，不设置倒计时、输赢或评分；允许不规则和小失误成为作品的一部分。
目标是首次进入后约一分钟学会操作，三到十分钟完成第一件作品。

## 2. 重做的由来

首版的三款游戏都是一次生成的，效果不好。具体是三件事：

1. **连贯感被按钮打断。** 织布机每织一行要依次点「开始织布」「穿完这一行」
   「压紧这一行」；剪纸要点「开始剪」才能下剪刀；水面印花要点「铺纸」「揭起纸」
   才能转印。这些都是手本来就在连续做的动作，被拆成了确认步骤。
2. **物理上说不通。** 剪纸把折好的纸按**旋转**复制成四层 / 八层，而纸是真的折起来
   再剪的，展开必然是**镜像**对称；水面印花存的是"调色板序号"，换一套配色会让
   已经滴进水里的颜料跟着变色。
3. **画面偏花。** 织出来的布是一格一格的实心方块，读起来像马赛克而不像布；
   水面印花的颜料是 200×140 的明显像素块。

这次重做的判据就是反过来：

- **手一直在动，中间没有确认。** 连续的动作全部由拖动直接产生结果。
- **结果必须能用手边的东西解释。** 折纸就是镜像，颜料滴进水里就是那滴颜料。
- **安静。** 三款都只用纸、木、水本身的质感，不加装饰性的渐变和光效。

## 3. 六条设计原则

1. **一次手势，一个结果。** 拖动到对岸就成行、剪过就留痕、纸上按下去就吸住花纹。
   不设"准备 / 确认 / 完成"这类中间态按钮。
2. **几何要能用手解释。** 任何对称都由折叠方式推出来，任何形变都由工具的运动方向
   推出来。写不出物理过程的对称，就是错的。
3. **状态是绝对的，不是累加的。** 指针位置直接映射到进度，不逐帧累加位移 ——
   方向中途翻转时累加会算错（织布机实测会在 1 行和 0 行之间抖）。
4. **素材全部自己画。** 没有第三方图片；音效用 WebAudio 现场合成。
5. **简洁。** 一屏之内看得完，工具靠边，撤销与导出始终找得到。
6. **两种输入同等对待。** 鼠标拖动与单指拖动走同一套 pointer 事件，
   手势面必须 `touch-action: none`，否则触屏滑动会被浏览器拿去滚页面。

## 4. 小小织布机

**体验目标：**看着一根根线变成布，享受穿梭的重复节奏。

**核心流程：**选经线配色 → 按住布面横向拖动 → 这一趟到岸就自动成行、自动换梭口、
自动打紧 →（随时换梭线）→ 收边 → 导出。

- **一次拖动就是一行。** 没有「穿完这一行」，也没有「压紧这一行」。指针走到对岸，
  这一行就落下；手还在继续走只是停在岸边，不会误判。
- **进度按指针的绝对位置算。** 落在布的横向上哪一点，梭子就在哪里 ——
  所以梭子永远在手底下，不存在"抓住时算错偏移"导致的漂移。
- **布从下往上长。** 第 0 行贴底梁，新行压在前一行上面，没织到的经线绷在上方通向
  顶梁。这是立式框织机的真实情形；反过来画（布堆在顶梁、裸线垂在下面）会像布吊在
  半空。
- **布面按连续的经线 + 连续的纬线画。** 竖带贯穿整幅、用虚线实现"一上一下"，
  相邻经线错开半格 —— 这就是平纹的定义，也正好是棋盘格的反面（布有连续的经纬）。
- **反悔走工具栏的「退回一趟」。** 不做"把梭子拽回起点"的手势：到岸之后方向就翻面了，
  手顺着手势多走一段会被当成往回拽，刚织好的行把自己退掉。
- 经线四方案（燕麦 / 靛青 / 野莓 / 苔原），上机后不可再换（换经线要重新上机）；
  梭线八色可逐行换，换色只影响之后织的行。
- 收边后给出带流苏的成品图，可导出 PNG。

**完成标准：**玩家能连着织出多行、中途换色不破坏已织的部分，成品看得出是一块布。

## 5. 剪纸窗花

**体验目标：**通过少量剪切获得复杂图案，在展开时得到惊喜。

**核心流程：**选纸色与折法 → 在折好的纸上直接拖出切口（边拖边见）→
拖展开的进度条把纸拉开 → 放到窗前看 → 导出透明底 PNG。

- **折叠产生的是镜像，不是旋转。** 折数与层数的关系是 `层数 = 2^折数`；
  展开后的图形是二面体群 D_n，`n = 2^(折数-1)`，相邻镜像轴相距 `π/n`：
  - 两折（4 层）：D_2，一条竖轴 + 一条横轴（四个象限互为镜像），相邻轴 90°；
  - 三折（8 层）：D_4，八条镜像轴，相邻轴 45°。
  实现上第 k 层是"绕楔形中线镜像"再"旋转"，等价于 `旋转(θ_k) ∘ 镜像`（k 为奇数时镜像）。
  单测钉住：楔形内一条竖向切口展开后，整体关于竖轴镜像对称。
- **没有「开始剪」。** 指针在楔形纸上一划就留下切口，松手即是一刀。
  剪刀走过的宽度就是切口的宽度（有实际的纸厚）。
- **展开是连续的。** 拖进度条把折叠的纸拉开，途中能看到一层层翻开；
  不是"点一下跳到展开态"。
- 「放到窗前」保留为视图切换（换背景），这是展示选择，不是创作闸门。
- 「撤销一刀」、纸色五选、折法二选；已下刀后不宜改折法，改法与织布机一致（明确拒绝并提示）。
- 导出透明底 PNG，可直接叠在窗景上。

**完成标准：**切口与展开结果对应清楚；展开的花纹关于折叠轴镜像对称，不是风车状。

## 6. 水面印花

**体验目标：**不需要绘画基础，也能通过滴色和拖动得到有层次的花纹。

**核心流程：**选配色 → 向水面滴颜料 / 用针或梳子拖纹理 →
把纸拖下来按进水面 → 向上拖动揭起纸 → 得到印张 → 导出 PNG。

- **颜料把颜色烘进每一处。** 存的是颜色值本身，不是调色板序号 ——
  换一套配色不会让已经在水里的颜料变色。单测钉住这条：
  用 A 配色滴色、切到 B 配色，已有颜料的颜色必须逐字节不变。
- **颜料平滑，不是像素块。** 模拟网格可以小，渲染时要插值 / 轻微模糊再放大。
- **梳子出的是垂直的齿。** 按拖动方向算法线，沿法线位移，得到一排平行的细纹；
  针拉出一条干净的细弧。两者都不该是一团糊。
- **铺纸与揭纸是拖动。** 没有「铺纸」「揭起纸」按钮：往下拖把纸按进水面，
  往上拖把纸揭起来看印张。两个方向都可回退。
- 「撤销」回退上一笔；「换一盆清水」清空水面，会毁掉当前花纹 —— 必须二次确认。
- 三种工具（滴管 / 针 / 梳子）、四套配色；成品带轻微纸纹，可导出 PNG。

**完成标准：**滴色和拖动立刻改变花纹；换配色不改变已有颜料；纸上保留揭起时的图案。

## 7. 共用体验与边界

- **界面：**中央是制作台，工具与颜色靠边；撤销和导出始终容易找到。
  电脑用鼠标，手机用单指拖动；先选工具再动手，不依赖悬停或右键。
- **反馈：**保留材料质感与必要的制作动效；音效由 WebAudio 合成、可一键静音
  （页头与游戏内共用同一个音频引擎，静音是全局的）。关键反馈同时用画面表达。
- **减少动态效果：**折叠、展开、铺纸与揭纸直接到终态，交互不依赖动画时长。
- **保存：**每款游戏在当前浏览器各存一份草稿，刷新后可以继续。
  解析失败或版本不符的旧草稿直接丢弃，回到新作品状态；写盘失败时明确提示。
- **接入：**纯客户端单人小游戏，沿用玩具区的访问闸门与专注模式规则；
  没有新增库表、接口或鱼干奖励。

## 8. 落地

- **入口：** 玩具 → 测试 → 手工间合集 `/game/collections/test/craft` →
  `/game/loom`、`/game/papercut`、`/game/marbling`。
- **代码分层：**每款游戏一份 `engine.ts`（零 DOM、零 React，单测直接 import）
  加一份视图组件；页面外壳、音效、草稿钩子、导出是 `src/games/craft/` 下的共用件。
- **草稿键：**`craft-loom-v2`、`craft-papercut-v2`、`craft-marbling-v2` ——
  形状变过就升版，旧键的数据由 `parse*` 按版本号拒掉。
- **导出：**三款都导出 PNG（剪纸保留透明底；织布与水面印花的成品与屏幕上看到的
  用同一份画法，导出不会变成另一种质感）。
- **减少动态效果：**见上；e2e 全程以 `reducedMotion: 'reduce'` 跑，交互不得依赖动画时序。
- **测试：**纯模型由 `tests/unit/craft-{loom,papercut,marbling}.test.ts` 覆盖；
  完整操作链路（含刷新续作与 PNG 导出）在 `tests/e2e/craft-games.spec.ts`；
  「用到的类名必须有样式」由 `tests/unit/css-tsx-classes.test.ts` 静态对账。

## 9. 后续方向

可增加制作过程回放、作品分享，以及每人贡献一小段的公共长布；
织布机可扩斜纹与自由抬线，剪纸可扩自由折纸与立体纸雕，水面印花可扩颜料混合与多种纸材。
这些是可选扩展，尚未排期。
