# 每日一言发行与结算

## 1. 发行与阅读

站点按 UTC+8 日期发行每日一期。后台 `startDailyQuotePublisher` 在启动和跨日时确保当天已发行；同日重试复用既有发行记录。读者访问、刷新和签到只读取发行结果。历史缺日保持空缺，下架或归档后保留原日期占位。这一决定把当天内容与第一位访客的到达时间解耦。

社区稿须通过审核、作者仍具参与资格且从未选登。先按候选数的 `log(n+2)` 权重抽作者，再均匀抽取该作者的一条稿件。首次选登标记与当日期次同事务写入；具体选稿策略由 `src/lib/daily-quote-service.ts` 实现。社区候选用尽后，内置经典按使用历史轮换。读者、投稿人与审核人的权限及用户操作见 `docs/guide/每日一言使用指南.md`。

## 2. 审核、共鸣与收藏

重审沿用稿件 ID，以递增版本绑定正文和审核结果。管理员可将未通过稿件软删除并恢复，审核记录与版本继续保留。匿名稿的身份披露遵循对应读口权限。每人对每条内容累计共鸣一次，同一条内容再次发行也沿用已有互动。一笔共鸣与实际鱼干转账分别记录，发生转账时与账目同事务提交。旧互动明细和既有流水保留。

一言集对本人可见，收藏日期取首次加入时间。内容下架后保留可移除的占位。管理、发行与交互规则变更时同步受影响的玩家说明。

## 3. 迁移与回退

发行日期唯一；同一经典内容可出现在多个日期。历史迁移从已有期次回填社区首次选登日，并为旧稿保存基线版本。部署、核对与回退条件见 `docs/deploy.md` §4。
