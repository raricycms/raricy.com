# 收藏夹使用指南

把喜欢的文章收进自己的收藏夹，整理成一个个「合辑」；公开的收藏夹还能分享出去。

---

## 一、收藏一篇文章

在文章详情页底部，点赞和投喂的右边有一颗**五角星**，点它就会打开收藏夹选择器。
星标**没收藏时是灰的，收藏之后才亮成黄色** —— 和旁边的点赞、投喂一样，看一眼颜色就知道状态。

- **同一篇文章可以同时放进多个收藏夹**（所以选择器是复选框，不是开关）。
- 收藏夹按钮上**没有数字**。本站不显示一篇文章被收藏了多少次 —— 收藏夹可以复制，
  那个数字并不代表「多少人在读它」，反而容易被误当成对作者的认可。
- **作者不会收到任何收藏通知。** 收藏是给自己整理用的，不是给对方的信号；要表达喜欢请用点赞或投喂。

首次使用会提示「还没有收藏夹」，在同一个弹窗里就能建。

### 去哪儿管理收藏夹

**顶栏右上角头像 → 我的收藏夹**（`/favorite`）。创建、改名、删除、导出、导入都在这一页；
也可以从收藏夹选择器弹窗右下角的「管理收藏夹 →」直接过去。

> 手机上点赞、投喂、收藏三颗会**并排压在同一行**，星标是最右边那颗。

## 二、私密还是公开？—— 建的时候就要选，之后不能改

新建收藏夹时有两个入口：**创建私密收藏夹** / **创建公开收藏夹**。这两个不是外观差异，
而是**两种东西**：

| | 私密收藏夹 | 公开收藏夹 |
|---|---|---|
| 谁能看到 | **只有你自己** | 任何核心用户 |
| 有没有 6 位 ID | **没有** | 有（例如 `[@123456]`） |
| 分享二维码 | ❌ | ✅ |
| 被机器人 / 爬虫读取 | ❌ | ✅ |
| 用 `[@ID]` 嵌进文章 | ❌ | ✅ |
| 导出 JSON 文件 | ✅ | ✅ |
| 复制成另一种 | ✅ | ✅ |

**创建后性质不可修改** —— 所以两个入口是分开的，好让你在建之前就看清自己要建的是哪种。
想换性质，用下面的「复制」。

### 为什么私密收藏夹「没有 ID」

不是「有 ID 但不给你看」，而是**真的没有**。这样它就不可能通过任何途径泄露出去 ——
不存在一个「小心别把它贴出去」的 6 位数字。所以私密收藏夹页面上也不会出现任何 ID
（包括「ID 已隐藏」这种提示，因为并没有一个被藏起来的东西）。

## 三、复制收藏夹（快照）

打开一个收藏夹，有**复制为私密收藏夹**和**复制为公开收藏夹**两颗按钮：

- 在别人的公开收藏夹页面上，可以把整份复制成**自己的**一份 —— 这是「收下别人的合辑」的方式。
- 在自己的收藏夹上，可以复制成另一种性质 —— 这是**唯一**改变性质的办法。

> ⚠️ **复制出来的是快照。** 只复制**点击那一刻**的标题与文章列表，之后两份各走各的：
> 你在这边加一篇，那边的副本不会跟着加；你删掉原收藏夹，副本照样在。
> 想要「永远跟着更新」，只能自己再复制一次。

## 四、分享一个公开收藏夹

打开公开收藏夹，页面上会显示它的 6 位 ID 和几个分享方式：

1. **分享二维码** —— 生成一张画报，扫码即可打开。适合发在聊天里或贴到别处。
2. **`[@123456]` 嵌进文章** —— 在**博客正文**或**云剪贴板正文**里写 `[@123456]`，
   会渲染成一张收藏夹卡片（标题 + 条目数 + 前 10 篇的链接，超出部分有「查看全部」）。
   - 评论区与讨论区**不支持**这种嵌入，会原样显示 `[@123456]`。
   - 一篇文章最多嵌 **3 张**收藏夹卡片。
   - 卡片里的文章标题是**别人写的**，其中若恰好也有 `[@...]` 形状的文字，不会被再解释一次。
3. **直接把链接发出去** —— 地址形如 `https://raricy.com/favorite/123456`。
   打开这一页需要**登录且是核心用户**（本站的博客区都是这样），游客打不开。

> 想让机器人或爬虫读取？它们走免认证的 `/api/spider/favorites/<6位ID>`，
> 口径见站外开发文档（`docs/bot/favorite-bot.md`）。

## 五、导出与导入 JSON

### 导出

打开收藏夹（私密也行），点**导出 JSON**，会下载一个文件，内容是：

```json
{
  "version": 1,
  "title": "值得重读的几篇",
  "blogs": [
    { "id": "9f8c1d2e-…", "title": "第一篇的标题", "url": "https://raricy.com/blog/9f8c1d2e-…" }
  ]
}
```

**文件里没有收藏夹 ID，也没有「私密 / 公开」标记。** 所以私密收藏夹也能放心导出 ——
拿到文件的人无法从它反推出这是谁的那个收藏夹。

### 导入

在「我的收藏夹」页面上点**选择文件**，挑一个 JSON，然后选**导入为私密收藏夹**
或**导入为公开收藏夹**。

- 导入**总是新建一个收藏夹**，不会并进已有的那个。
- 文件里的 ID / 是否公开等信息会被**忽略**，新收藏夹的性质以你导入时选的为准。
- 找不到的、已删除的文章会被跳过，导入完会告诉你「新增几篇、跳过几篇」。
- 一个收藏夹最多 1000 篇。

## 六、上限与次数

| 项目 | 上限 |
|---|---|
| 每个用户的收藏夹数量 | **200 个** |
| 每个收藏夹的文章数量 | **1000 篇** |
| 新建 / 复制收藏夹 | 20 次 / 小时 |
| 加入 / 移出文章 | 300 次 / 小时、1500 次 / 天 |
| 导入 | 10 次 / 小时 |

删除收藏夹**会**让出配额 —— 建满 200 个之后删掉一些，就又能建了。
（删除只是从你这边隐藏，收藏夹中的文章本身不会被删除。）

## 七、常见问题

**删掉收藏夹，文章会没吗？**
不会。收藏夹只是「一组链接」，删收藏夹不动文章，也不动别人的收藏夹。

**为什么我收藏了文章，作者没收到通知？**
故意的。收藏是给自己整理用的；本站也不公开任何一篇的被收藏数。

**为什么我看不到某个 6 位 ID 对应的收藏夹？**
它可能是私密收藏夹（不存在对应的 ID），或者已经被删除了。这两种情况对外是一样的。

**一篇能同时放进很多个收藏夹吗？**
能，不限个数（受每个收藏夹 1000 篇的上限约束）。
