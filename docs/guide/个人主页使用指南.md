# 个人主页使用指南

个人主页（`/u/<用户 ID>`）是你在站外的名片。别人扫主页画报上的二维码、点评论或讨论里的头像，都会来到这里。

它由两部分组成：

- **上半截是固定的身份条**：头像（含头像框）、用户名、角色、简介、注册日期。这部分不可布置，资料在「账号设置」里改。
- **下半截是积木墙**：你自己挑内容、自己摆位置。访客看到的就是你摆的这一页。

## 一、谁可以布置

**核心用户及以上**可以布置自己的主页。非核心用户仍能正常查看和分享自己的主页，只是暂时不能编辑，页面底部会说明这一限制。

进入编辑的入口只有一个：身份条上的「**布置主页**」按钮。第一次打开、还没布置过时也是它（页面里的引导和空态只说明怎么用，不再另放按钮）。

## 二、能放什么

一块「积木」可以是下面七类之一：

| 块 | 内容来源 | 说明 |
|----|----------|------|
| 文章 | 你**对外可读**的文章（公开或凭链接可读） | 卡片显示标题、摘要和发布日期；高的卡片还会显示一段正文摘要。点击进入文章 |
| 图片 | 图床里**公开**的图片 | 可加一行说明；点击查看大图 |
| 音频 | 音频床里**公开**的音频 | 可改标题，访客可以直接播放 |
| 文字 | 直接写一段纯文本 | 可加一行小标题，最多 200 字 |
| 链接 | 一个站外地址 | 只接受 `http` / `https`；显示文字默认取域名 |
| 统计 | 自动读取 | 对外文章数、获赞数、累计签到天数 |
| 签到 | 自动读取 | 累计签到天数 |

规则：

- 一页最多 **16 块**。
- 每块有 **四档尺寸**：小（一格）、宽（横两格）、高（竖两格）、大（四格）。内容是纯文本，不接受 Markdown 或 HTML。
- **块里只放本来就对外可读的内容。** 文章、图片、音频在挑的时候只列出已经对外公开的那些；放上之后如果内容被删、改回站内、图片改成私有，这一块在访客眼里会直接消失（不是显示旧标题）。
- 没布置过时，主页默认显示你最近三篇对外可读的文章；如果不想这样，可以在「账号设置 → 主页隐私设置」里关掉「默认展示最近文章」，默认主页就会是空的。

## 三、在电脑上布置

1. 打开自己的主页，点身份条上的「**布置主页**」。编辑工具条会立刻出现，页面进入编辑态。
2. 在底部的「加一块」里选类型：文章 / 图片 / 音频会让你从已有内容里挑一个，文字和链接会弹出填写框，统计和签到直接加。
3. **拖动卡片**换位置：桌面是 4 列方格，卡片可以摆在任意空格上，允许留白，不允许两块重叠。
4. **点一下卡片**选中它：卡片上会出现操作条，可以换尺寸、编辑内容、删除；选中后也能用方向键微调位置、按 Delete 删除。
5. 点右上角「保存」提交；不想改了就点「放弃」。有未保存的改动时，工具条会写「有未保存的修改」，离开页面前浏览器也会提醒。

保存成功后页面会**立刻显示新版**，不需要手动刷新；地址里的编辑参数也会被清掉，刷新不会重新进入编辑态。

## 四、在手机上布置

手机上看到的是电脑布局折成两列的结果，**不是另一套顺序**：

- 电脑上的**相邻两列 = 手机上的一个列**：电脑第 1–2 列的块进手机左列，第 3–4 列的块进右列。
- **宽块**（宽、大两档，也就是横跨两格或更多的块）在手机上**占满一行**，不管它在电脑上摆在哪两列。
- 上下顺序按电脑上**从左到右、从上到下**的阅读顺序排；电脑上刻意留的空行在手机上不会保留。所以想调整手机上的先后，本质上是在调电脑上的位置。

手机上的操作：

1. 点「**布置主页**」进入编辑态。卡片左上角会出现一个**把手**。
2. **按住把手，拖到另一张卡片上松手**，两块就交换位置。手机上只有把手能拖 —— 直接拖整张卡片会和页面滚动抢手势。
3. **点一下卡片**选中它，底部工具条会从「加一块」切换成这一块的操作：
   - 换四档尺寸；
   - **左移 / 右移**：把一格的块换到另一半（宽块本来占满一行，这两颗会置灰）；
   - **上移 / 下移**：和**同一列**的上一块 / 下一块交换位置（不会把隔壁列那块一起换走）；
   - 编辑内容、删除。
4. 点工具条右上角「完成」或点空白处取消选中，回到「加一块」。
5. 点「保存」提交。

手机上的移动改的就是电脑上的位置：保存后电脑端打开会是同一份布局。保存后同样立刻显示新版，不用刷新。

## 五、查看主页

- 访客看到的就是你保存的那一页；没布置过时是默认布局或空态。
- **点文字块**（查看态，不是编辑态）会弹出一个居中的详情层，把这块文字完整放大显示。按 Esc、点四周的暗色背景、或点右上角关闭都能退出。
- 图片块点开是大图；文章块点进文章；链接块在新标签页打开站外地址；音频块可以直接播放。

## 六、内容不可用之后

如果主页上某一块指向的文章改回了站内、图片改成了私有，或者内容被删除：

- 访客看不到这一块（它不会显示空卡片或旧标题）。
- 你自己进入编辑态时，会看到「这块内容已不可用」和「换一个」；点它可以从当前可用的内容里重新挑一个，位置和尺寸保持不变。
- 这类块不会阻止你保存其他改动。

## 七、其他说明

- 主页**不进入搜索引擎**。凭链接可读的文章可以挂在主页上，但主页不会被索引。
- 身份条上的头像、头像框与简介来自「账号设置」；换头像框也在设置页操作。
- 自己的主页右上角可以「生成画报」：保存成图片后发到任何地方，扫上面的二维码就能打开你的主页。
- 主页是公开名片，请不要把只给特定人看的内容放上去 —— 能放上来的块，本来就都是对外可读的。
