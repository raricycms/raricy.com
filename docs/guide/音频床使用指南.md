# 音频床使用指南

音频床用来存放音频文件，并给你一条可以贴到任何地方的直链。它与图床是**两套独立的
空间** —— 音频不占图片的额度，图片也不占音频的。

**音乐和语音留言都用它**。两者在站里没有区别，只是时长不同；同一个 10 MB 上限
把两种用法一起管住。

## 一、谁能用

需要**核心用户（Core）及以上**角色，也就是通过邀请码认证之后。

各角色的额度：

| 角色 | 音频额度 |
|------|---------|
| Core | 50 MB |
| 管理员 | 50 MB |
| 站长 | 100 MB |

Core 与管理员**同额**，这是有意的，不是漏配。角色的分档见站点说明。

## 二、上传

**工具箱 → 站务工具 → 音频床**（`/audio`）。把文件拖进上传区，或者点一下选文件。
一次一个文件。

上传成功后卡片会出现在下方，可以：

- 直接在卡片里**试听**（拖动进度条也可以）；
- 点复制按钮拿**音频 ID**；
- 点外链图标在新窗口打开原始文件；
- 删除。

## 三、把音频贴进正文

音频文件本身只是一条直链。要让它在正文里**出现一个播放器**，写这个语法：

```
[@音频/你的音频ID]
```

例如音频 ID 是 `AbCdEf1234`，就写：

```
[@音频/AbCdEf1234]
```

渲染出来是一个可以播放、可以拖进度条的播放器。

**能用的地方**：博客正文、云剪贴板正文、评论区、讨论区，四处都支持。

**一条正文里最多展开 3 个音频**。超出的部分原样显示成 `[@音频/…]` 字面量，
不会报错 —— 这是刻意的上限，因为每个音频都是几 MB 的传输量。

想**展示这个语法本身**（而不是让它变成播放器），把它写进代码块或行内代码里：

```
`[@音频/AbCdEf1234]`
```

## 四、限制一览

| 项目 | 限制 |
|------|------|
| 支持格式 | MP3、M4A、OGG |
| 单文件大小 | 10 MB |
| 存储额度 | Core / 管理员 50 MB，站长 100 MB |
| 上传频率 | 每小时 200 次 |

10 MB 大约是多长的一段音频，取决于码率：

| 码率 | 10 MB 大约 |
|------|-----------|
| 128 kbps（常见语音 / 播客） | 约 10 分钟 |
| 192 kbps | 约 7 分钟 |
| 320 kbps（高码率音乐） | 约 4 分钟 |

**额度用完时**：50 MB 大约能放 5 个满额（10 MB）文件。删掉不再需要的音频会立刻
把额度还给你 —— 额度是按**没有删除的**文件算的。

## 五、格式与兼容性

站点**不做转码**，你传上去的是什么，别人下载到的就是什么。所以格式选得对不对，
直接决定别人能不能播：

- **MP3** —— 兼容性最好，任何浏览器、任何播放器都能放。不确定就选它。
- **M4A**（AAC）—— 苹果设备录音的默认格式，Mac / iPhone / 主流浏览器都支持。
- **OGG**（Opus / Vorbis）—— 体积效率好，但**Safari 对它的支持比较差**。
  如果你自己用 Safari，传 OGG 可能听不了，建议换 MP3。

**不支持** WAV 与 FLAC。它们是无损格式，体积大得不成比例 —— 一分钟 WAV 就有
10 MB，正好等于单文件上限，收进来只会给你一个「传什么都失败」的入口。
需要无损请先转成 MP3 / M4A。

## 六、音频 ID 与直链

每条音频有两个东西可以复制：

- **音频 ID** —— 10 位字母数字，用来写 `[@音频/ID]` 引用语法；
- **直链** —— `/api/audio/<ID>/raw`，可以贴到站外（比如论坛、聊天软件）。

直链是**公开的**：拿到链接的人不需要登录就能听。所以不要把不该外传的音频传上来。

站外的机器人要用这套接口，见 `docs/bot/audio-bot.md`。

## 七、常见问题

**传上去说「不支持的文件格式」？**

三种可能：格式确实不在白名单里（比如 WAV / FLAC）；文件扩展名与实际内容对不上
（把 `.mp3` 改名的其他格式）；或者这是一个 OGG 容器装的**视频**。站点是按文件
**内容**判断格式的，不看扩展名。

**传上去说「文件过大」？**

单文件上限 10 MB。用音频编辑软件重新导出一遍，降低码率即可 —— 语音类内容
64～128 kbps 完全够用，体积能小一个量级。

**传上去说「存储空间不足」？**

额度是按**未删除**的文件总大小算的。去 `/audio` 删掉不再需要的，额度立刻恢复。

**播放器拖不动进度条？**

正常应该能拖。如果拖不动，先刷新页面；仍然不行请反馈 —— 进度条依赖服务端的
分段传输支持，那条链路坏掉的表现就是「能播但不能拖」。

**为什么别人看得到我的音频，而我没分享过链接？**

引用语法 `[@音频/ID]` 会把播放器直接渲染进正文。如果你把带引用的文章设为对外可见，
读到那篇的人就都能听到。这是一条**直链**，不是需要登录的私有文件。

**能把音频当附件发在讨论区吗（像图片那样）？**

不能。讨论区和评论区的图片附件走的是另一套机制，音频**只有** `[@音频/ID]`
这一条路。语音留言也是贴引用语法。

**给表情合集起名「音频」会怎样？**

不会生效，而且会被跳过。「音频」与「用户」一样是**保留合集名** ——
表情语法 `[@合集/表情]` 与 `[@音频/ID]` 形状相同，不占住这个名字就没法区分。
换一个合集名即可。
