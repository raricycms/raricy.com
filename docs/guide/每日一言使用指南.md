# 每日一言使用指南

## 一、签到后查看

完成签到后会自动打开每日一言弹窗。关闭后，可以在签到页点击「查看今日一言」重新打开。
签到与鱼干到账仍然一次完成；一言加载失败时可单独重试。

全站当天显示同一句，按 UTC+8 零点换日。系统从审核通过、最近90天未选用的站友投稿中随机选取，
没有可用投稿时从300条内置经典语录中随机选取。当天的选择会保存，刷新、重启都不会换句。
下架后的当天一言显示下架提示，当天不另选一句。

弹窗底部有「往期一言」和「一言集」两个入口；「我的投稿」在签到页与相关页面的导航里。

## 二、往期一言

签到页随时可以进「往期一言」（`/checkin/quotes`），浏览系统实际选用过的往期，**不含今天**。
今天的查看规则不变，仍然要签到。

- 按日期倒序，每天一期，每页 20 期；分页有首页、末页与跳页，页码超出范围会归到有效页。
- 不需要当天签到，也不需要曾经收藏；新成为 core+ 的用户也能回看全部已公开的往期。
- 只列真正入选过的期。还没有人读过今日一言的那天不会产生选择，历史里就是空缺 ——
  不补抽，也不拿候选池或当天的稿件凑数。
- 通过审核但从未入选、待审核与被拒的稿件都不出现在这里。
- 同一句在 90 天后再次入选，会保留两个日期条目；两处的共鸣与收藏状态按同一句共享。
- 已下架或作者已归档的期只保留日期和「该日内容已不可用」，不显示原文、出处与作者，
  不能新增共鸣或收藏；已经收藏的仍可在「一言集」移出。
- 每条卡片写明日期、类别与来源（经典 / 站友投稿、署名 / 匿名），费用写在操作旁边；
  「站友投稿共鸣投喂 1 条鱼干，经典免费」这条通用规则在列表顶部说明一次。

## 三、共鸣

- **每人每句一生最多一次**：同一句一言，每个账号只能共鸣一次。换日、取消收藏、重新收藏、
  90 天后再次入选都不会恢复资格；今日弹窗、往期和一言集看到的是同一个状态。
- 已生效的共鸣不能取消，也不会再扣款；重复点击返回同样的「已共鸣」结果，人数不增加。
- 站友投稿：首次共鸣从你的余额扣除 **1条鱼干**，全额投喂给投稿人。
- 经典语录：共鸣免费，不扣鱼干，也不向任何人发放鱼干。
- 不能给自己的投稿共鸣。余额不足时不会产生共鸣或扣款。
- 共鸣人数按**人数**统计（同一人只算一次），不是次数。旧规则允许跨日重复共鸣，
  上线后个别内容显示的共鸣数可能比之前少；已经发生的鱼干流水不回收、不重算。
- 每日一言的查看与操作仅向 core+ 用户开放；禁言期间不能投稿、共鸣或变更收藏。
- 投稿人被降为普通用户、禁言或归档后，不能通过共鸣获得新的鱼干。

匿名投稿仍然可以收到投喂；向付款方展示的一言与付款流水不会暴露投稿人的真实账号。
共鸣支出和收入可在鱼干流水的「共鸣」分类查看。

## 四、收藏到一言集

点击「收藏」会直接加入「我的收藏夹 → 一言集」，再次点击可以移出。
一言集固定为私密分类，只有本人可查看，不生成公开句柄。
收藏与共鸣互不影响：没有共鸣也能收藏，取消收藏也不会撤销或重置共鸣。

一言集显示每条的**最近入选日期**（这条内容最近一次被选为每日一言的日期），不是收藏时间；
没再入选的旧内容可以一直保留收藏。列表分页与往期一致。
内容下架或作者归档后变为占位，仍可移出收藏。
一言集为空时，可以直接去「往期一言」看看，不必等下一次签到。

文章收藏夹的公开、复制与导入导出规则见 `docs/guide/收藏夹使用指南.md`；一言集是独立分类，
不参与文章合辑的分享、复制与导入导出。

## 五、投稿与审核

在弹窗点击「我也要投稿」，或进入签到页的「我的投稿」。

- 正文最多 **50字**，可选治愈、搞笑、扎心、励志或哲思。
- 可选择昵称署名或匿名。匿名隐藏对其他用户的署名，管理员仍可查看投稿人。
- 来源可选原创或引用；引用必须填写原作者或作品出处，最多100字。
- 每人24小时最多投稿 **5次**，投稿后不能修改正文或署名。
- 待审内容不会进入每日抽取或其他用户的收藏。
- 管理员通过后进入内容池，通过不代表立即展示。
- 被拒绝的稿件永久拒绝，不能重新通过；同一内容更改标点也不能重复投稿。
- 「我的投稿」展示最近100条稿件的状态及审核说明。

管理员在「管理面板 → 一言审核」处理待审稿件，拒绝与下架必须填写原因。

## 六、经典语录来源

内置目录位于 `src/data/daily-quote-classics.json`，每条保存作者、原文作品名及在线原文链接。
内容选自《论语》《道德经》《孟子》《荀子》《庄子》《墨子》《韩非子》《礼记》《菜根谭》
以及李白、杜甫、王维、苏轼等人的公版作品，仅使用原文摘句，不包含现代译文。
正文按所链接版本核对，保留该版本用字；不以网络转述替代原文。

## 七、接口与维护

所有接口使用 core+ 会话，写请求同时校验禁言与站内同源规则：

| 接口 | 作用 |
|---|---|
| `GET /api/daily-quotes/today` | 今日一言及本人状态，未完成今日签到返回403 |
| `GET /api/daily-quotes/history?page=1` | 往期一言及本人状态，不含今天，每页20期 |
| `GET /api/daily-quotes/submissions` | 本人最近100条投稿 |
| `POST /api/daily-quotes/submissions` | 投稿：`content`、`category`、`signature`、`source_type`、可选 `source_name` |
| `POST /api/daily-quotes/:id/resonance` | 共鸣，重复请求不重复扣款 |
| `POST /api/daily-quotes/:id/favorite` | 加入本人一言集 |
| `DELETE /api/daily-quotes/:id/favorite` | 移出本人一言集 |
| `PATCH /api/admin/daily-quotes/:id` | admin+ 审核：`action` 为 `approve` / `reject` / `retire`，附 `reason` |

`signature` 为 `nickname` 或 `anonymous`，`source_type` 为 `original` 或 `quotation`。
接口响应沿用站内 `code` / `message` 形状。

共鸣资格由累计去重表 `daily_quote_resonance_once` 判定（每人每句一生一次）；每次实际发生的
日期与当次金额另存明细，只用于审计。资格行、明细行、扣款与入账在同一事务提交，失败全部回滚。
共鸣接口返回服务端确认的 `resonated` / `can_resonate` / `resonance_count`，页面以响应为准，
不按本地旧值累加。读今日一言时惰性确定当天选择，不需要额外定时任务；往期列表只读已经存在的
选用记录，不会为今天或过去补抽。上线按仓库既有迁移流程执行，手写迁移同时建表并导入300条经典内容。
