# 每日一言使用指南

## 一、签到后查看

每日一言面向 core、admin、owner。使用相关页面或主动操作前，本人名下需要至少一篇未删除的
博客；没有博客或已全部删除时，页面会引导先发表一篇自我介绍。已有任何一篇未删除的博客
即可，不要求标题或内容必须是自我介绍。普通用户不能参与，也不能通过本功能获得鱼干。

完成签到后会自动打开每日一言弹窗。关闭后，可以在签到页点击「查看今日一言」重新打开。
签到与鱼干到账仍然一次完成；一言加载失败时可单独重试，不影响已经到手的签到奖励。

全站当天显示同一句，按 UTC+8 零点换日。**每条站友投稿最多选登一次**，审核通过后等待首次
选登，不存在经过90天重新进入池子的规则。可选稿件按审核通过时间取用；昨日是社区稿且有
其他作者的候选时，优先选其他作者等待最久的一条。没有可选社区稿时，从300条内置经典中
选择从未使用或最久未使用的内容；经典可以循环使用。

当天的选择会保存，刷新、重启都不会换句。下架或作者归档后显示不可用提示，当天不另选一句。
每日一言主页为 `/quotes`，统一提供今日、往期一言、我的收藏和我的投稿。
签到页只保留今日一言快捷查看与主页入口；旧往期、投稿、一言集地址会携带查询参数跳转到新路径。

## 二、往期一言

已有博客的 core+ 可以随时进入「往期一言」（`/quotes/history`），浏览系统实际选登过的往期，
**不含今天，不要求今天签到**。今天的查看规则仍然是先签到。

- 按日期倒序，每天一期，每页20期；页码超出范围会归到有效页。
- 新成为 core+ 的用户在发表博客后也能回看全部可读往期，不要求当时来过或曾经收藏。
- 只列真正存在的期。没有人读取今日一言的日期不会产生选择，历史缺日不补抽。
- 待审核、审核未通过，以及通过但从未选登的稿件都不在往期里。
- 经典可以出现在多个日期；旧规则已经留下的社区重复期次原样保留，但不会再选登。
  同一句的共鸣、人数和收藏状态在不同期次间共享。
- 下架或作者归档的内容只保留日期和不可用提示，不能新增共鸣或收藏，已收藏的仍可移出。
- 作者仅被降级、禁言或删除全部博客时，已经选登的原文不会因此从往期消失。

## 三、共鸣

- **每人每句最多一次**，生效后不能取消。换日、取消或重新收藏、经典再次入选都不重置资格。
- 站友投稿的投稿人当前可以收款时，从共鸣者扣除 **1条鱼干**，全额交给投稿人；原创与引用同样处理。
- 投稿人当前不是 core+ 或处于禁言等不能收款状态时，仍可共鸣，**共鸣者不扣鱼干，投稿人也不收鱼干**。
- 经典共鸣免费，不向任何人发放鱼干。免费共鸣不要求共鸣者有余额。
- 投稿人恢复收款资格后，先前的免费共鸣不补扣、不补发，也不能再次共鸣。
- 收款资格按 core+、未归档和未禁言判断，不要求收款人当天签到，也不额外要求其仍保留博客。
  下架和归档的不可读规则优先，不会因为免费共鸣而重新开放原文。
- 不能给自己的投稿共鸣。应付费但余额不足时，整次操作失败，不会自行改为免费共鸣。
- 已共鸣的重复请求不重复扣钱、不增加人数；显示人数按不同账号统计，不按次数统计。
- 共鸣、投稿、改稿和收藏变更需要当前为 core+、有未删除博客且未被禁言。
  禁言中的账号可以回看往期、收藏与本人投稿，但不能执行写操作。

按钮会显示当前费用。页面展示免费后，如果收款资格恢复导致本次需要付费，会先更新费用并
提示再次点击，不会意外扣钱。成功反馈以服务端实际扣款为准。匿名投稿仍可收款，普通读口与
付款流水不暴露匿名投稿人的真实账号。实际发生的共鸣支出和收入可在鱼干流水的「共鸣」分类查看。

## 四、收藏到一言集

点击「收藏」直接加入「我的收藏夹 → 一言集」，再次点击可以移出。一言集固定为私密分类，
只有本人可查看，不生成公开句柄。收藏与共鸣互不影响，没有共鸣也能收藏。

一言集按**收藏时间**倒序显示，主要日期为「收藏于……」。社区稿可辅助显示选登日期，经典
可显示首次选登日期；经典后来重播不会改变收藏时间，也不显示其最近重播日期。
重复的加入请求保留原收藏时间；取消后重新加入则记录本次重新收藏的时间。

收藏是内容引用，原文下架或作者归档后变为占位，仍可移出，不会保留一份可继续阅读的原文副本。
空的一言集可以直接进入往期寻找内容，不必等待下一次签到。
文章合辑的分享、复制和导入导出规则见 `docs/guide/收藏夹使用指南.md`；一言集不参与这些流程。

## 五、投稿与审核

在弹窗点击「我也要投稿」，或进入签到页的「我的投稿」。

- 正文最多50字，分类为治愈、搞笑、扎心、励志或哲思。
- 可选择昵称署名或匿名；匿名只对其他用户隐藏，管理员仍可查看投稿人。
- 来源可选原创或引用，引用必须填写100字以内的原作者或作品出处。
- 每人24小时最多投稿5次；「我的投稿」展示最近100条。

稿件有四个正常状态：

| 状态 | 含义与后续操作 |
|---|---|
| 待审核 | 作者可修改正文、分类、署名与来源，保存后仍需审核，不消耗新的投稿次数 |
| 已通过未选登 | 已进入首次选登候选，不能编辑；通过不代表今天展示，也不承诺具体日期 |
| 已选登 | 显示选登日期，原文继续留在往期，不能再进入每日候选，也不能编辑 |
| 审核未通过 | 显示审核意见；修改后可以用原投稿重新提交审核 |

未通过后可以只修正出处、署名或分类，不必强迫改变原文。重新提交计入24小时5次配额，
沿用原稿件编号，增加一个版本并回到待审核；旧版本和对应审核意见保留。规范化后完全没有
变化时需要先修改再提交。只换标点等不能把正在审核、已收录或已下架的内容重复收录。

审核未通过的正文不会被永久封锁；与其他正在审核或已经收录的稿件冲突时，仍需避免重复。
已审核通过的稿件暂不提供作者改写或撤回；管理员仍可说明原因后下架，下架不重置曾经选登的事实。

投稿人失去 core+、处于禁言或删光博客时，未选登稿件暂停候选，资格恢复后可以继续候选；
审核状态不会自动变成未通过。已选登的内容可见性与收款规则分别按前文执行。

管理员在「管理面板 → 一言审核」处理稿件，可分开查看待审核、已通过未选登、已选登、未通过、
下架和内置经典。未通过与下架必须说明原因。作者和管理员均可查看稿件版本及审核历史。
作者改稿后，旧审核页面的操作会被拦住，需要刷新确认最新版本；改了又改回原文也不能复用旧审核页面。

## 六、经典语录来源

内置目录位于 `src/data/daily-quote-classics.json`，每条保存作者、作品名及在线原文链接。
内容选自《论语》《道德经》《孟子》《荀子》《庄子》《墨子》《韩非子》《礼记》《菜根谭》
以及李白、杜甫、王维、苏轼等人的公版作品，仅使用原文摘句，不包含现代译文。
正文按所链接版本核对，保留该版本用字，不以网络转述替代原文。

## 七、接口与维护

所有业务接口使用 core+ 会话并检查博客前置；写请求另校验禁言与站内同源规则。未登录返回401，
档位或博客条件不满足返回403，博客条件失败附 `reason: BLOG_REQUIRED`。响应沿用 `code / message`。

| 接口 | 作用与参数 |
|---|---|
| `GET /api/daily-quotes/today` | 今日一言及本人状态，未签到403，包含当前能否投稿的 `can_submit` |
| `GET /api/daily-quotes/history?page=1` | 往期及本人状态，不含今天，每页20期 |
| `GET /api/daily-quotes/submissions` | 本人最近100条，含 `display_status`、数字 `version`、`first_selected_day` 与 `history` |
| `POST /api/daily-quotes/submissions` | `content`、`category`、`signature`、`source_type`、可选 `source_name` |
| `PATCH /api/daily-quotes/submissions/:id` | 字段同投稿，另需最新数字 `version`；待审保存或未通过后原稿重审 |
| `POST /api/daily-quotes/:id/resonance` | JSON 必须带 `max_fish`（0或1），表示本次最高可扣鱼干；返回实际扣款 `charged_fish` |
| `POST /api/daily-quotes/:id/favorite` | 加入本人一言集，重复加入不改变收藏时间 |
| `DELETE /api/daily-quotes/:id/favorite` | 移出本人一言集，下架内容也允许移出 |
| `PATCH /api/admin/daily-quotes/:id` | admin+ 审核，`action` 为 `approve / reject / retire`，附 `reason` 和审核页下发的字符串版本摘要 `version` |

`signature` 为 `nickname / anonymous`，`source_type` 为 `original / quotation`。
作者编辑用数字版本，审核用包含版本号与字段内容的摘要，两者不能互换。旧页面缺少版本或金额时需要刷新。
从免费变收费且超出 `max_fish` 时返回409及 `reason: FEE_CHANGED`，没有产生扣款或共鸣。
已经共鸣过的重复请求返回 `already_resonated: true`，本次 `charged_fish` 为0，不重新付费。

共鸣累计资格仍由 `daily_quote_resonance_once` 判定，日期及当次金额另记明细。资格、明细、
实际扣款及收款同事务提交；免费路径只记零金额明细，不生成零金额鱼干流水。客户端以服务端
返回的人数和按钮状态为准，不在本地自行累加人数。

社区首次选登标记与当期记录同事务写入，经典以历史记录轮换。读今日时惰性确定当天选择，
往期纯读、不补抽。新增的版本表和活动正文条件唯一索引走仓库手写迁移流程；存量所有社区
选登历史都用于回填首次日期，旧重复期次、共鸣、收藏及鱼干记录不删除、不改账。
迁移基线版本只代表升级时保存的快照，不伪造此前未留存的修改历史。
