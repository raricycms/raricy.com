# 编辑器使用指南

博客发文（`/blog/upload`）与云剪贴板（`/clipboard/upload`）用的是**同一个** Markdown
编辑器，工具条与快捷键两边一致。

## 手机上的工具条

窄屏（≤767px）工具条默认只留三件最常做的事 —— **表情**、**上传图片**、**插入引用** ——
其余全部收在**「更多工具」**里：标题、粗体 / 斜体 / 删除线、链接、无序 / 有序 / 任务列表、
缩进、引用、代码块、行内代码、公式、表格、撤销 / 重做、导出。

点一下「更多工具」展开，再点一下收起。**展开时那颗开关自己不会挪位置**，所以连点两下
不必重新瞄准；展开出来的按钮接在同一行里往后排，一行排不下就换行，不会被裁掉。

宽屏（≥768px）没有这颗开关 —— 工具条本来就是完整的一排，手机首行那三件与「更多工具」
里的那些**原样都在**。

## Enter 与 Shift+Enter

- **Enter** 保留 Markdown 的书写习惯：在 `- 列表项` / `> 引用` 那一行末尾回车会**接着
  续写下一项的标记**；光标夹在一对括号（`()`、`[]`、`{}`）中间时会**补一个空行**。
- **Shift+Enter 只换一行**：它什么都不多做，就在光标处插一个换行。地址、歌词、
  「想换行但不想分段」的地方用它。

两者的差别只在**成品里怎么显示**：本站正文的渲染开关是 GFM + `breaks`，**普通段落里
单个换行就显示成换行**（不必写 `<br>`，也不必在行尾补两个空格），**连着按两次才是新的
一段**。这一条说的是普通段落 —— 代码块里怎么显示由代码块自己决定，与按哪个键无关。

## 放进正文的资源

图片、音频、剪贴板、投票、收藏夹这五类内容走**「插入引用」**（挑已有的）或
**「上传图片」**（新传一张），落进正文的是一枚 `[@…]` 引用；它们各自的语法见
`docs/guide/内容引用语法指南.md`。

## 工具条上还有的

- **标题**：下拉里选级别，选「正文」会脱掉 `#`。
- **表格**：插一套三行的骨架（表头 / 分隔 / 一行内容），接着自己往下加行。
- **导出**：导出 HTML，或走打印另存为 PDF。
- **预览**：切到预览是**只读**的（改不了正文），窄屏不提供「并排」这一档，宽屏才有。
