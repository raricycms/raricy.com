# 聊天气泡使用指南

聊天气泡改变你在讨论大区和私聊中发出的文字消息外观。每个人可以持有多款，但同时只使用一款；默认气泡免费且一直可用。

## 1. 租用与选择

在 `/fish/market#shop` 的鱼干商城选择「聊天气泡」，查看预览和租金，填写租期，确认后扣除鱼干并获得使用资格。购买不会自动换气泡，到 `/settings#chat-bubble` 点击「使用」即可，也可以随时恢复默认。

目前两款示范气泡均为 **10 鱼干 / 月**：

| 名称 | key | 外观 |
|------|-----|------|
| 蓝底直角 | `blue-square` | 蓝色底、直角；原「蓝色直角」更名，已购租期和装备保留 |
| 蓝色直角 | `blue-outline-square` | 蓝色边框、直角，底色与聊天区一致 |

1 个月固定 30 天，单次可租 1–12 个月。没有自动续费。两款分别持有和续期。

重复购买会续期：还没到期时接在原到期之后，已经到期时从本次购买起算。永久持有者无需再次租用。购买与头像框共用商城租赁限频。

## 2. 展示与到期

所有历史消息也跟随作者当前选择的气泡；切换后已打开的聊天窗口会同步刷新。断线或推送失效时，聊天页每 60 秒向服务端校正气泡状态，到期也通过这个快照回到默认，无需手动卸下。

两款都适配深浅主题：浅色主题用深色文字，深色主题用浅色文字。「蓝底直角」的蓝底也随主题变深浅，以保持文字清晰；「蓝色直角」的底色跟随聊天区。被 @ 提及时，蓝底款加深底色，描边款加粗边框。

拍一拍、删除占位、引用摘要及独立图片/博客卡保持固定的展示方式。纯图片和纯表情沿用透明外层规则。气泡不改变正文、通知、消息未读或已读回执。

停售只阻止新的租赁，不影响尚未到期的持有资格；停用则会回到默认气泡。撤销写软删标记，不删除持有记录。

## 3. 站长发放与新增款式

`npm run cli -- bubble list` 查看定义和租金；`bubble list <用户名>` 查看持有状态。

`npm run cli -- bubble grant <用户名> blue-square --days 7` 发放 7 天，省略 `--days` 为永久；发放只延长不缩短，不会替用户装备。`npm run cli -- bubble revoke <用户名> blue-square` 撤销资格并恢复默认，两种操作都记录审计日志。

款式定义、名称和租金住 `src/lib/bubble-refs.ts`，共享租期住 `src/lib/shop-refs.ts`。当前款式通过 `ChatBubble` 和 `src/styles-scss/pages/_chat.scss` 渲染，无外部素材依赖；新款要同时补白名单定义、样式和真实消息/预览验证。移除 `rent` 表示停售，设置 `disabled` 表示停用，不删除 key。

持有/装备/购买的事务规则见 `src/lib/bubble-service.ts` 与 `src/lib/bubble-shop-service.ts`。新增款式不需要数据库迁移。
