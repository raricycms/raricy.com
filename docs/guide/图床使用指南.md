# 图床使用指南

图床是 Raricy.com 提供的图片托管服务：上传图片后获得一个 10 位图片 ID，可生成直链在任意页面使用，也可以直接嵌入博客文章。图片会由服务器自动压缩处理，节省空间。

---

## 前置条件

使用图床需要已登录且通过邀请码认证（Core 用户及以上角色）。如果尚未认证，请先联系站长获取邀请码。

---

## 一、主页面

访问地址：`/image`

顶部标题下方提供"使用指南"入口（即你正在阅读的文档；站长另有"管理所有图片"入口）。主页面自上而下依次是：

- **配额条**：显示"已用 X MB / 上限 Y MB"及百分比，超过 80% 后进度条变色提醒。
- **上传区**：拖拽图片到此处，或点击选择文件。
- **图片网格**：你上传的全部图片，最新上传的排在前面。

> 配额按账号累计：Core / 管理员为 50 MB，站长为 100 MB。删除图片可以释放配额。

---

## 二、上传图片

支持 **PNG / JPEG / GIF / WebP / SVG** 五种格式，单文件上限 **10 MB**。

上传前有一个默认勾选的开关：

- **压缩图片（减小文件体积，轻微损失画质）**：勾选（默认）时，服务器会把超过 2000px 的图片等比缩小，并对位图重新压缩（JPEG/WebP 质量约 85，PNG 无损压缩）；GIF 与 SVG 不压缩。如果压缩后体积反而更大，会保留原图。
- 取消勾选：原样存储，不做任何压缩。

上传时页面会显示进度条；上传成功后网格自动刷新，新图片出现在列表最前面。

> 服务端会校验文件内容与声明的格式是否一致（防止改扩展名混入非图片文件），伪装的文件会被拒绝。上传频率限制为每小时 75 次。

---

## 三、图片网格与操作

每张图片卡片显示：缩略图、文件名、文件大小（KB）、10 位图片 ID。悬停在卡片上可看到三个操作按钮：

| 按钮       | 说明                                |
| -------- | --------------------------------- |
| 复制 ID    | 把 10 位图片 ID 复制到剪贴板，按钮短暂变成对勾 |
| 新窗口打开    | 在新标签页打开图片原图直链                  |
| 删除       | 确认后删除（软删除，见下文）               |

点击缩略图会打开大图预览，支持点击遮罩或按 `Esc` 关闭；预览中同样可以复制图片 ID（站长还会看到"图片管理"入口）。

---

## 四、分享与嵌入

### 直链

每张图片都有固定直链：

```
/api/images/<图片ID>/raw
```

例如 ID 为 `AbCdEf1234` 的图片，直链为 `/api/images/AbCdEf1234/raw`。

在 Markdown 中使用图片：

```markdown
![图片说明](/api/images/AbCdEf1234/raw)
```

直链的特征：

- **公开图片无需登录即可访问**，分享给任何人。
- 浏览器会缓存一年（图片 ID 唯一、内容不变，可放心缓存）。
- 删除图片后直链返回 404（图片裂图）。
- SVG 出于安全考虑以**附件下载**方式打开，不会在浏览器内直接内联渲染。
### 嵌入博客

在博客正文中写入 `[@图片ID]`，发布后会自动替换为图片，图片支持点击放大：

```markdown
这是图片示例：

[@AbCdEf1234]
```

> 图片 ID 为 10 位，与 8 位剪贴板、9 位投票不同；长度不符的 `[@...]` 不会被处理。

### 编辑器直传

博客与剪贴板编辑器（Vditor）工具栏的图片按钮会上传到图床，插入的即是上面的直链格式。一次一张，只收位图（PNG / JPEG / GIF / WebP）——SVG 请先在本页上传，再用 `[@图片ID]` 引用。

---

## 五、删除与配额

- **删除（普通）**：删除图片后它从你的列表中消失，直链变为 404。删除为软删除——占用配额会**立即释放**。
- **站长永久删除**：站长在图床管理页可以"永久删除"任何图片，会同时删除磁盘文件与记录，**不可恢复**，并会给图片上传者发送站内通知。

## 六、限制一览

| 限制项        | 数值                        |
| ---------- | ------------------------- |
| 存储配额（Core/管理员） | 50 MB（站长 100 MB）           |
| 单文件大小      | ≤ 10 MB                    |
| 支持格式       | PNG / JPEG / GIF / WebP / SVG |
| 上传频率       | 每小时 75 次                  |
| 压缩           | 位图 >2000px 缩放 + 有损/无损重压缩，可关闭 |
| 图片 ID       | 10 位（大小写字母 + 数字，区分大小写）    |

## 七、常见问题

### Q: 上传提示"不支持的文件格式"？

图床只接受 PNG / JPEG / GIF / WebP / SVG。图片内容与声明格式不符时，会提示"文件内容与声明的格式不匹配"。

### Q: 上传提示"存储空间不足"？

你的账号配额已用完。删除部分图片释放空间后即可继续上传（删除为软删除，配额立即释放）。

### Q: 别人能看我的图片吗？

能。目前上传的图片默认公开，任何人拿到直链都能查看——请勿上传隐私或敏感内容。仅历史遗留的私有标记图片会限制为作者与站长可见。

### Q: 图片在博客里裂图了？

图片可能已被删除（直链返回 404）。请到 `/image` 重新上传并更新引用。

### Q: 为什么 SVG 点开是下载而不是显示？

防止 SVG 中嵌入脚本造成安全风险，图床的 SVG 一律以附件形式下载，这是有意设计。
