# 国际象棋联机对战

## 简介

8×8 的棋盘，白先黑后。王车易位、吃过路兵、兵升变这些边角规则全都实现了，
不是「简化版」。

玩具区里国际象棋有**单机**和**联机**两个入口，进去是同一个页面：
单机是两个人挤在同一块屏幕前轮流走（不需要登录），联机是隔空对弈。

## 开始之前

- **需要一个核心用户（core）及以上的账号。** 联机是社交玩法，与聊天、评论同一个门槛。
  普通账号在注册时填写有效的邀请码即可升级为核心用户。
- **专注模式开启时无法联机。** 页面会给出关闭入口，服务端也会拒绝。

## 开一局

1. 进入 **玩具 → 联机 → 国际象棋**，点「创建房间」。
2. 页面上会出现一个 **6 位房号**（例如 `K7M2QX`），地址栏里也会变成一条可直接分享的链接。
3. 点「复制邀请链接」，把链接发给朋友。
4. 朋友打开链接就会自动坐到你对面。

也可以反过来：朋友开了房，把房号告诉你，你在「输入 6 位房号」里填上再点「加入」。

> 房号里不会出现 `0`、`o`、`1`、`l`、`i` 这五个字符——它们靠人念、手抄、发消息时
> 最容易认错。大小写也不敏感。

## 对局

- **开房的人执白**（先手），加入的人执黑。
- **轮到你走**时才能走子。先点一下自己的棋子，能去的格子会亮出来，再点目标格即可。
- 轮次由服务端判定，抢不走也跳不过。
- 走错了一步？**联机没有悔棋**。单机模式有「悔棋」按钮。

### 规则要点

| 棋子 | 走法 |
|------|------|
| 王 | 周围一格。**不能走到被对方攻击的格子上**，也不能贴着对方的王 |
| 后 | 直线、横线、斜线任意格 |
| 车 | 直线、横线任意格 |
| 象 | 斜线任意格（每只象一辈子只走一种颜色的格子） |
| 马 | 走「日」字，可以跳过别的棋子 |
| 兵 | 向前一格；第一次可以走两格；**斜着吃子**；不能后退 |

三条容易踩坑的规则：

- **王车易位**：王向车的方向走两格，车跳到王的另一边。前提是王和那个车都没动过、
  中间没有子、王**不在被将**、王经过的格子和落点**都不被对方攻击**。
  注意：车经过的格子被攻击不影响易位。
- **吃过路兵**：对方的兵第一次走两格、正好从你的兵旁边擦过去时，你可以立刻斜吃掉它——
  但要**紧接着这一手**吃，过了就没了。
- **兵升变**：兵走到对方底线时变成后、车、象或马，**由你选**，页面会弹出选择条。
  通常升后，但偶尔升马是唯一的赢法，所以这里不会替你决定。

还有一条：**任何让对方能吃掉你王的走法都是非法的**（比如被牵制的子不能乱动）。
走不了就是走不了，点了不会有反应。

### 怎么算结束

- **将死**：对方被将军且无路可走 → 对方输。
- **逼和**：对方**没有被将军**，但一步也走不了 → **和棋**。
  这一条和中国象棋正好相反（那边叫「困毙」，算输）。
- **和棋**还有几种：50 回合内双方都没吃子也没动兵；双方子力都不足以将死对方
  （比如只剩光王）；同一个局面出现三次。
- 对局中随时可以**认输**。

## 掉线与判胜

网络断了、标签页关了、电脑合上了——都算掉线。席位栏里会标出「（掉线）」。

- 掉线的一方**座位还留着**。重新连上（刷新页面、重新打开链接）就会回到原来的位置，
  不会变成观众，也不会被别人顶掉。
- 对手掉线满 **60 秒**后，你可以点「判胜」直接赢下这一局。按钮上会显示倒计时。
- 对手在这 60 秒内连回来了，判胜资格立即取消。
- 时间以**服务器**为准，改本地时钟没有用。

## 观战

两席坐满之后，再打开链接的人自动成为**观众**：能看到同一张棋盘，实时同步，
但棋子是点不动的，也没有认输之类的按钮。一间房最多 20 位观众。

## 再来一局

分出胜负后，双方都可以点「再来一局」。**两边都点了**才会重开，一个人点只是申请，
按钮上会显示「已申请，等对手」。重开后棋盘回到开局，**黑白不变**（开房的人还是白）。

## 房间有效期

房间是临时的，不会一直留着：

- 一局结束后或长时间没人动，房间会在 **30 分钟**后过期。
- 建完房一个人都没进来、也没人连着，**2 分钟**后就回收了。

房间过期后链接会失效，页面会提示「房间已失效」，重新开一间即可。

## 常见问题

**朋友打不开链接？**
链接里带着房号，对方需要先登录，并且账号是核心用户及以上。没登录会被引导到登录页，
登录完会自动回到这个房间。

**刷新页面会不会丢座位？**
不会。刷新等于重新连上，仍然坐原来的位置。

**能同时开好几局吗？**
每种棋各自最多同时开 4 条连接（多标签页、多设备加起来）。超了会被拒绝，
关掉多余的标签页即可。

**别的棋的房号能拿来下国际象棋吗？**
不能。房号是各自游戏内部的事，走错门只会提示「房间不存在」——重新开一间即可。

**有 AI 对手吗？**
暂时没有。单机模式是同机双人（两个人轮流走同一块屏幕）。

**积分、战绩、排行榜呢？**
暂时没有。现在的联机只负责把一局棋下完，不记录结果。
