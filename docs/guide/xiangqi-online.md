# 中国象棋联机对战

## 简介

9 路 10 行的棋盘，红先黑后，把对方的将（帥）将死就赢。规则完整：马蹩腿、象塞眼、
炮翻山、兵过河才能横走，一样不少。

玩具区里中国象棋有**单机**和**联机**两个入口，进去是同一个页面：
单机是两个人挤在同一块屏幕前轮流走（不需要登录），联机是隔空对弈。

## 开始之前

- **需要一个核心用户（core）及以上的账号。** 联机是社交玩法，与聊天、评论同一个门槛。
  普通账号在注册时填写有效的邀请码即可升级为核心用户。
- **专注模式开启时无法联机。** 页面会给出关闭入口，服务端也会拒绝。

## 开一局

1. 进入 **玩具 → 联机 → 中国象棋**，点「创建房间」。
2. 页面上会出现一个 **6 位房号**（例如 `K7M2QX`），地址栏里也会变成一条可直接分享的链接。
3. 点「复制邀请链接」，把链接发给朋友。
4. 朋友打开链接就会自动坐到你对面。

也可以反过来：朋友开了房，把房号告诉你，你在「输入 6 位房号」里填上再点「加入」。

> 房号里不会出现 `0`、`o`、`1`、`l`、`i` 这五个字符——它们靠人念、手抄、发消息时
> 最容易认错。大小写也不敏感。

## 对局

- **开房的人直接坐红方那一席**（先手）。点开链接的人先落在观战台上，点黑方
  那一席上的「加入」才入座 —— 坐哪一席就执哪一方。
- **轮到你走**时才能走子。先点一下自己的棋子，能去的格子会亮出来，再点目标格即可。
- 轮次由服务端判定，抢不走也跳不过。
- 走错了一步？**联机悔棋要对手同意**：点「悔棋」发出请求，对手点「同意」才回退。
  撤到**你上一次走子之前** —— 你刚走完撤 1 步；对手已经应了招，就连他那一步一起撤（2 步）。
  对手拒绝就接着下；请求发出后不冻结棋局，谁再走一手它就作废。

### 规则要点

| 棋子 | 走法 |
|------|------|
| 帥 / 將 | 每次一格直线，**不能出九宫**（棋盘上画了斜线的那个 3×3 方框） |
| 仕 / 士 | 每次一格斜线，同样不能出九宫 |
| 相 / 象 | 每次两格斜线（走「田」字），**不能过河**；田字中心有子就走不了（塞象眼） |
| 馬 | 走「日」字；先直行的那一格有子就跳不过去（蹩马腿） |
| 車 | 直线任意格，不能穿子 |
| 炮 / 砲 | 不吃子时走法同車；**吃子必须隔一个子**（炮架），隔着吃掉它后面的第一个敌子 |
| 兵 / 卒 | 每次向前一格；**过河之后**还能左右各一格；永远不能后退 |

还有一条容易被忽略的规则——**飞将**：两个将（帥）不能在同一条直线上照面。
所以任何会让两王面对面的走法都是非法的，包括「把挡在中间的子挪开」。

### 怎么算结束

- **将死**：对方被将军且无路可走 → 对方输。
- **困毙**：对方**没有被将军**，但一步也走不了 → 对方**也输**。
  这一条和国际象棋正好相反（那边叫「逼和」，算和棋）。
- **和棋**：60 回合内双方都没有吃子；或者同一局面出现三次。
- **长将判负**：如果重复出现的局面里，某一方每一步都在将军，那么**这一方判负**
  （不是和棋）。
- 对局中随时可以**认输**。

## 掉线与判胜

网络断了、标签页关了、电脑合上了——都算掉线。席位栏里会标出「（掉线）」。

- **对局进行中**：掉线的一方**座位还留着**。重新连上（刷新页面、重新打开链接）就
  回到原来的位置，不会被别人顶掉。
- **没在对局中**（还没开局、或上一局已经结束）：掉线就等于把席位**让出来** —— 席位当场
  空出、人回到观战台，别人可以点「加入」补位。切到别的标签页也算断开，所以回来时会
  **自动坐回原位**（还空着的话）；被抢先坐了，就只好当观众。
- 对手掉线满 **60 秒**后，你可以点「判胜」直接赢下这一局。按钮上会显示倒计时。
- 对手在这 60 秒内连回来了，判胜资格立即取消。
- 时间以**服务器**为准，改本地时钟没有用。

## 大厅：席位与观战台

没在对局中时（刚开房、或上一局已经结束），房间里摆着两样东西：

- **对战席位**：两个位置，坐上去的人显示头像和用户名。空着的那一席是个写着「加入」的
  按钮 —— 点一下就坐上去；已经坐在另一席的人点它，按钮写的是「换先」（换个先后手）。
  想跟对手互换座位没有这回事：等他起身，或者自己退到观战台再坐过去。
- **观战台**：房间里其他人在那儿排着，同样有头像和用户名。坐在席位上的人点
  「去观战台」就能退下来，把位置让给别人。

两席都坐上人，对局就开始，**观战台随之隐藏**（只剩两张席位和「围观 N」）。一间房最多
20 位观战。

## 观战

两席坐满之后，再打开链接的人落在**观战台**上：能看到同一张棋盘，实时同步，
但棋子是点不动的，也没有认输之类的按钮（对局中不显示名单，只显示「围观 N」）。

## 再来一局

分出胜负后，双方都可以点「再来一局」。**两边都点了**才会重开，一个人点只是申请，
按钮上会显示「已申请，等对手」。重开后棋盘回到开局，**席位不变**（谁坐哪一席就执哪一方）。

## 房间有效期

房间是临时的，不会一直留着：

- 一局结束后或长时间没人动，房间会在 **30 分钟**后过期。
- 建完房一个人都没进来、也没人连着，**2 分钟**后就回收了。

房间过期后链接会失效，页面会提示「房间已失效」，重新开一间即可。

## 常见问题

**朋友打不开链接？**
链接里带着房号，对方需要先登录，并且账号是核心用户及以上。没登录会被引导到登录页，
登录完会自动回到这个房间。

**刷新页面会不会丢座位？**
不会。刷新等于重新连上，仍然坐原来的位置 —— 对局中一定如此；没在对局中时，只要你那一席
还空着也会自动坐回去（被抢先坐了就只能当观众了）。

**能同时开好几局吗？**
每种棋各自最多同时开 4 条连接（多标签页、多设备加起来）。超了会被拒绝，
关掉多余的标签页即可。

**别的棋的房号能拿来下象棋吗？**
不能。房号是各自游戏内部的事，走错门只会提示「房间不存在」——重新开一间即可。

**积分、战绩、排行榜呢？**
暂时没有。现在的联机只负责把一局棋下完，不记录结果。
