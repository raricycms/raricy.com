# 格式转换器使用指南

格式转换器在「工具箱」里（`/tool/convert`），把一种文件变成另一种文件 —— 图片换格式、
视频提音频、PDF 取文字、表格换 JSON、老压缩包换 ZIP…… 共八个能力区。

**它与别的转换网站最大的不同：文件不出你的浏览器。** 整个转换在你的设备本地完成
（图片走浏览器自己的解码器，音视频走一份下载到本地的 FFmpeg 引擎），服务器既收不到
你的原文件，也收不到转换结果。断网之后只要引擎已经加载过，照样能用。

## 基本用法

页面按「添加文件 → 设置输出 → 转换结果」排列。电脑上文件与设置并排，手机上依次向下显示。

1. 打开 `/tool/convert`，点顶部的类别标签（图片 / 音频 / 视频 / 文档 PDF / 表格数据 /
   文本字幕 / 电子书 / 压缩包）。
2. 把文件**拖进「添加文件」区域**，或点「选择文件」。一个任务可以带多个文件（比如多张图合成
   一份 PDF）。
3. 页面识别文件内容后，列出**这个文件真的能转**的目标 —— 识别靠文件内容（魔数），
   不是靠扩展名猜，所以把 `.txt` 改名成 `.png` 混不进来。
4. 在「设置输出」中选好格式、调好参数（高级参数默认折叠），点**开始转换**。
   文件与目标格式匹配后，按钮才会启用；按钮下方会说明尚缺哪一步。
5. 在「转换结果」中预览、逐个下载，或点「打包下载全部成功结果」保存为一个 ZIP。

各类别的格式与限制收在文件区下方的「支持的格式与使用限制」里。

任务**排队逐个执行**：转换是重计算，同时跑多个只会一起变慢。转换中可以随时取消；
取消了重试不冲突。

## 每次转换都会告诉你「丢了什么」

转换完成后，结果区会列出**保留与损失说明** —— 这是这个工具的硬规矩，举几个例子：

- PNG 转 JPG：「有损重编码」「透明区域已压平到所选背景色」「EXIF 元数据不保留」
  （元数据不保留同时也是**隐私特性**：照片的拍摄地点不会跟着转出去）。
- XLSX 转 CSV：「公式只保留计算结果，公式本身不保留」「其余 N 个工作表未转换」。
- PDF 逐页导出图片：「文字层不保留（输出是图片，不能再选字）」。
- 老压缩包（RAR / 7Z）转 ZIP：「时间戳与文件属性不保留」。

**反过来也一样**：一条目标当前设备上做不出来（比如浏览器不支持编码 AVIF），它就不会
出现在菜单里，而不是让你转出一个坏文件。

## 用途预设与固定配方

通常直接选择输出格式、调整参数即可。需要自动填写时，可以展开「设置输出」下方默认
收起的**常用转换方案（可选）**：「手机照片发给别人」「视频只要声音」「扫描资料取文字」
「表格给程序处理」…… 这里只显示当前类别的方案。
点一下就把目标与参数填好，你还可以再改。预设在添加文件前后都可选择，切换同类用途会
保留已选文件；修改参数后，预设不再显示为选中。

**固定配方**是「转换 + 打包」的组合（比如「一组 HEIC → JPG → 打成 ZIP」），
收在同一个折叠区的「转换并打包」部分。

## 各能力区一览与上限

转换在你的设备上跑，所以每一类都有保护性上限（防止浏览器被吃光内存卡死）：

| 能力区 | 做什么 | 上限 |
|--------|--------|------|
| 图片 | JPG / PNG / WebP / AVIF / BMP / TIFF / ICO / HEIC 互转，SVG 栅格化，动图拆帧 / 合成 | 单张 20MB、1600 万像素 |
| 音频 | MP3 / WAV / FLAC / OGG / M4A / AIFF 互转，换封装 | 20MB、5 分钟、双声道 |
| 视频 | 转 MP4 / MKV / WebM、提取音频、转 GIF、抽帧、提取字幕 | 100MB、2 分钟、1080p |
| 文档 / PDF | PDF 逐页导出图片、图片合成 PDF、提取文字、合并 / 拆分 / 重排、压缩、扫描件 OCR | 50MB、300 页 |
| 表格数据 | CSV / TSV / XLSX / JSON / NDJSON / YAML / XML 互转 | 20MB、20 万行 |
| 文本字幕 | 文本编码转换（GBK / Big5 / Shift_JIS 等）、SRT / VTT / ASS 字幕互转 | 10MB |
| 电子书 | Markdown / HTML / TXT / DOCX 转 EPUB，EPUB 转回与解包 | 50MB |
| 压缩包 | ZIP / TAR / GZIP 互转与解包，RAR / 7Z 解包转 ZIP | 100MB、2000 个成员、解压后 500MB |

音频 / 视频 / 动图相关功能第一次使用时，需要**一次性下载约 30MB 的转换引擎**
（FFmpeg 的浏览器版），之后一直在本地。下载失败可以重试，不影响其它能力区。

## 几件值得知道的事

- **压缩包有安全闸**：成员数、解压总量、目录层级、压缩比都有上限，路径带 `..` 的
  成员会被拒绝（防「解压到任意目录」）。加密的压缩包暂不支持。
- **OCR 会出错字**：扫描件取文字（中英双语）之后请校对，结果页也会这么提醒。
- **真正的 DOCX 转 PDF 暂时没有**：那需要服务端的大型组件（LibreOffice），目前请先把
  DOCX 转成 Markdown / HTML，或用 PDF→DOCX（图片型）应付反向需求。菜单里看不到的方向
  就是还做不到， roadmap 里登记的将来方向不会出现在菜单里。
- **隐私的另一面**：转换过程不产生任何服务器记录 —— 没有历史列表可回翻，
  结果只活在这一页，刷新或关闭页面前记得下载。
- 任务输出总大小到 64MB 时队列会**暂停**，下载（或丢弃）已有结果后自动继续。
